Astolia Collabs could not start in this app window

The app itself is fine. The web engine inside this app window is either too old to run it or refused to load it.

On Android this is almost always one thing: Android System WebView is out of date.

  • Open the Play Store and update Android System WebView, then reopen this app.
  • If Google Chrome is providing the web view on this device, update Chrome instead. Updating either one is enough.

You do not have to wait for that. Astolia Collabs is a website as well as an app, and the website has every feature this app window has. Open the same link in Chrome, Safari, Firefox or Edge on this device and carry on there.

One thing to know: the app window and the browser keep separate copies of your data, because the operating system treats them as different sites. Nothing has been lost. If work was saved in this app window, it is still here once the app window starts, and moving it across is an export from one and an import into the other.
